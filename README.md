# 自主选课与排课系统 / Course Selection & Timetable Planner

单文件网页应用：`course-planner.html`（双击用浏览器打开，无需服务器、无第三方依赖）。
课程数据来自真实教学数据（3 个学期的完整排课 xlsx + 2 个官方课程开设表 PDF），由 `build/` 下的脚本生成并注入页面。

## 当前数据规模

| 项 | 值 |

## 文件

| 文件 | 说明 |
|---|---|
| `course-planner.html` | 应用本体：内嵌课程 JSON + 规则引擎 + 选课界面 + 课表界面（中英双语） |
| `build/pdf_rows.py` | PDF 课程开设表 → 行 JSON（FlateDecode + TrueType 文本抽取，纯标准库） |
| `build/build_catalog.py` | 合并 3 个 xlsx + 2 个 PDF → `data/catalog.json` + `data/report.md` |
| `build/major_map.json` | 官方专业表：31 个专业（学院 / 中英文名 / 对应课程标签），学院-专业筛选的数据源 |
| `补充材料/` | 31 份培养方案 PDF（每个专业一份），`major_map.json` 的专业名取自它们的 Programme Title |
| `data/catalog.json` | 课程目录（唯一数据源） |
| `data/report.md` | 解析报告：各学期统计、标签全量词表、未解析项、数据质量说明 |
| `embed-data.mjs` | 把 `data/catalog.json` 注入 `course-planner.html`（`--check` 只看统计） |
| `validate-catalog.mjs` | 数据校验器（结构、时间网格、午休、时长、教师/教室、辅导课、可行性抽样） |
| `smoke-test.mjs` | 规则引擎回归测试（真实页面代码 + DOM 桩，断言全部由当前数据推导） |
| `preview-gen.mjs` | 生成截图用的临时预览页 |

## 重建与验证

仓库里**已经包含**成品 `course-planner.html` 与 `data/catalog.json`，只想用应用的话直接打开 HTML 即可，下面这些只有想重新构建数据时才需要。

```powershell
<python> build/pdf_rows.py --pdf p1 --out build/_pdf_p1.json --report build/_pdf_p1_report.json
<python> build/pdf_rows.py --pdf p2 --out build/_pdf_p2.json --report build/_pdf_p2_report.json
<python> build/build_catalog.py            # data/catalog.json + data/report.md
node embed-data.mjs                        # 注入 course-planner.html
node validate-catalog.mjs                  # 数据校验
node smoke-test.mjs                        # 规则引擎回归
```

## 数据来源与合并口径

- **排课数据**：`ALL_UG_SIS_2025-26_Term_1 / _2025-26_Term_2 / _2026-27_Term_1.xlsx`（`Sessions` / `Tutorials` / `Enrollment` / `Courses` 四个 sheet，目录 1129 门）。旧版 `UG_Courses_SIS_*` 只覆盖 SDS/SSE/SAI/SME/MED，已停用。
- **补充课时**：`SUPPLEMENT_sessions_tutorials.xlsx`（每学期一张表，共恢复 **258** 门课；列顺序与 ALL_UG 不同——`类型` 在第 3 列，Session/Tutorial 混在同一张表，需专用读取器）。
- **删除无数据课程**：`NO_DATA_courses.xlsx`（`无数据课程` sheet，**431** 门：NOT_IN_CATALOG 1 门、NOT_SCHEDULED 185 门、NOT_OFFERED_IN_TERMS 245 门）整表删除。删除后目录里只剩 6 门 SAI 的 AIE 课程没有任何课时数据（按要求保留），因此"三个学期都显示本学期未开课"的情况基本消除。
- **课程属性**：两个官方开设表 PDF（2025-26 T2、2026-27 T1）提供 Target Students（年级/学院限制、通识判定、特殊标签）与课程标题。两张表的 Target Students 有 **103** 门不一致（如 `BIO 3901` 表一写 `MED (exclude CMED)`、表二写 `BIFC; BIOL; BME; PHAM`），**以较新的一张表为权威**；只有通识判定取并集（任一张写 `All UG Students` 即为通识）。
- **三个属性**：Units / Language 取自 xlsx（Language 缺失时默认 English）；Target Students 原文两张表都保留（PDF-only 课程同样保留，因为它是"仅限某专业"提示的唯一依据）。
- **先修 / 互斥**：xlsx 的结构化列优先，为空时从 `Enrollment Requirement` 原文抽取（"Students must take X first." / "cannot take" / "Exclusion: …"），再退回 PDF。
- **标签与"学院"的双重含义**（重要）：同一个学院代码（如 `HSS`）有两个互相独立的含义，数据里分成两组字段，界面也分两种样式：
  - `college` / `deptTags` = **开设学院**（PDF Department，缺失时用 xlsx Academic Group 映射）——只表示谁开课，**不限制其他学院选课**；
  - `studentTags` / `collegeRestriction` = **目标学生学院**，只来自 Target Students 原文——**这一项才会置灰**，且可能与开设学院不同（22 门）。
  - 其余 `tags` 成员（GE、特殊学生类型、特殊专业/方向）是标签，不参与选课校验。
- **通识判定**：`All UG Students`（大小写不敏感）**或**课程代码前缀属于 `PED` / `GEA` / `GEB` / `GEC` / `GED` / `CEC`（用户确认这 6 个系列全部为通识）→ `isGE = true`。通识课永不被学院限制置灰。
- **学院限制不再回退**：旧逻辑在"目标学生里没有学院"时默认限本院；现在学院限制**只来自 Target Students 原文**。因此仅点名专业/方向的课程（`majorOnly`，386 门）变成可自由选课 + 选课时弹提示，只写年级的课程（116 门）与完全没有目标学生数据的课程（55 门）一并开放。
- **先修限制传递**（新增规则）：一门课的**每一组**先修若都是学院限定课，则该课也受同样的学院限定——取各组学院限制的**并集**，迭代到不动点（新产生的限定会解锁下一轮）。例如 `BIO 2002` 先修 `BIO1001`（限 MED/SSE）→ `BIO 2002` 也限 MED/SSE；`BIM 3014` 先修 `(CSC1001 或 CSC1003 或 CSC1005); BIO1001` → 限 SSE/SDS/MED。仅当课程本身没有 Target Students 学院限制时才生效（不覆盖原文），通识课跳过（通识本来就不受学院限制）。本轮新增 **44 门**，迭代 3 轮。
- **课程级覆盖**（用户确认，写在 `build_catalog.py` 顶部的常量里）：PED 体育课一律 `Y1–Y1` 硬限制；`CHI`/`CEC` 系列一律中文授课（覆盖 xlsx 里的 English）；`PED 1101` 清空先修（体育课不应有 `ENG2002*` 先修，且这些课号并不在目录中）。
- **学院-专业两级筛选**（`build/major_map.json` + 每门课的 `majors` 字段）：专业表共 **31 个专业**，专业名取自 `补充材料/` 下 31 份培养方案 PDF 的 Programme Title，学院归属按学院-专业对照图，其中**金融工程按用户要求归入 SDS**。每个专业映射到一个既有课程标签（优先复用「特殊专业/方向」里的缩写；没有现成缩写的取专业名首字母，且必须与课程代码前缀一致，否则该专业筛不出课——例如应用心理学用 `PSY` 而不是字面的 `APSY`，因为目录里只有 `PSY` 开头的课）。课程上的 `majors` 字段即"该课命中了哪些官方专业"，共 **436 门课**至少属于一个专业，31 个专业都有课。
- **GEA / GEB / GEC / GED 系列**（用户确认，共 **73** 门）：PDF 里有的写 `All UG Students`、有的留空，统一改为 **Y2-Y4**（Y1 不可选）；全部加上「先修 `GFH 1000` 或 `GFN 1000`」（PDF 里写作 `Corequisite: GFH or GFN`，按先修要求建模：未满足时弹提示，仍可选）。其中点名了专业的课（`GEB 2508` / `GEB 2509`）保留专业名单并用 `targetTagText` 输出，选课时弹专业提示。
- **`GFH 1000` / `GFN 1000` 的 Y1 桥梁规则**：目标学生为 `Y1 (MSAIN_DMP; JTMSN_JOT); Y2-Y4 Students`，即这两个专业的学生 **Y1 即可选**，其余学生 Y2 起。数据上是 `y1Tags`（Y1 例外专业）+ `yearMin/yearMax = 2/4`（其余学生的下限），界面按学生身份标签判定：身份里含 `MSAIN_DMP` 或 `JTMSN_JOT` 时第一学年可选，否则弹 `仅限 Y2–Y4`。
- **Target Students 跨行溢出修补**（`merge_ge_target_spill`）：`GEB 2508` / `GEB 2509` 的目标学生整串文字在 PDF 里只排了一次并跨行，解析器把续行分给了 2509。修补后 2508 拿到完整名单、2509 更正为同一串（其单元格实际为空，与用户核对一致）。只对相邻两行都是 GE 系列、且下一行以 `)` 结尾时生效；`MUS`/`AIE` 等其它课程的同类截断不在此处理，以免把下一行的内容搬错。
- **已剔除**：`Registry` 名下的 Dummy / Exemption 占位记录（DUM、EXGBE、EXGBI、EXME、EXNE，共 43 门）。
- **按日期逐次排课**的课程（同一 session 每周时长不同，如 MED 2301A）合并为覆盖范围最大的时段，避免自我重叠。
- 出现 `Y5`/`Y6`（医学院临床课）的学年限制不参与逻辑。

## 规则

| 规则 | 判定 |
|---|---|
| 学院 | 非通识且 `collegeRestriction` 不含学生学院 → 置灰。来源有两种：Target Students 原文，或"先修全是学院限定课"传递而来；没有列学院的课程不再默认限本院 |
| 专业 / 方向 | `majorOnly`（目标学生只点名专业，未点名学院）→ **不置灰**，选课时弹提示由学生自行确认资格 |
| 年级 | 学生年级不在 `yearMin–yearMax` → 置灰（PED 体育课统一 Y1，Y2–Y4 置灰）。`y1Tags` 例外：身份里点名了这些专业时，第一学年也放行（`GFH 1000` / `GFN 1000`） |
| 互斥 | 任一方向命中 `exclusionCodes` 与已选课程 → 置灰（双向判断） |
| 先修 | `prereqGroups`（AND-of-OR）未满足 → 弹提示，仍可选。`GEA`–`GED` 系列的 `GFH 1000 或 GFN 1000` 也走这条（原文是共修课） |
| 同名课程 | 同一课程代码只能选一个 session（LEC/SUP/LAB/PRA/CLP/WKS/UGI 视为讲课类，辅导课互补） |
| 仅展示节次 | IDV/RSC/CLN/EXM/THE 类型只展示、按钮禁用；整门课都只有这类节次时课程标"仅展示" |
| 辅导课 | 该学期有辅导课时必须立刻选一门（弹窗强制），且遵守 40 分钟规则 |
| 时间 | 同一天重叠，或间隔 **< 40 分钟** → 冲突（恰好 40 分钟可选）；12:30–13:30 无课且视为满足 40 分钟 |
| 时间范围 | 08:30–21:50；起点 :00/:30；时长白名单由数据生成（20/50/80/110/140/170/230/260） |
| 多教室 | 同一 session 同一时段多个教室视为"老师决定教室"，全部保留并显示 |
| 周末 / TBA | 周末时段在课表下方单独列出、不进周一至周五网格；时间待定的 session 不进网格、不参与冲突 |
| 自定义模式 | 勾选后只保留"时间冲突"校验，其余限制（学院/年级/互斥/先修）暂停 |

## 界面

- **视觉风格**：配色与字体对齐 SAI 课程站（`sai.cuhk.edu.cn`）——主色紫 `#6a0dad`、点缀金 `#d4af37`、强调紫 `#a855f7`、深紫 `#4a1c6f`、淡紫底 `#f9f5ff → #f0e6ff`；字体为 `-apple-system / BlinkMacSystemFont / Segoe UI / Roboto / Helvetica / Arial`；顶栏为紫→深紫渐变 + 金色底边 + 双径向高光，页脚同款渐变。按钮与筛选胶囊为紫色圆角、金色用于强调（通识标签、激活态阴影、课表格线），弹窗顶部有金色横条。页面仍不加载任何外部资源（不引入 Font Awesome 等 CDN，保持双击即用的离线单文件）。
- **三个筛选开关**（只看本学期可选 / 只看可选的 / 自定义：仅校验时间）：原来是与背景同色系的淡灰小字、几乎看不见，现改为**有 1.5px 深紫边框的开关胶囊**（紫字 + 自定义方框勾选）；选中时整颗变紫、勾选框变金并出现 ✓。选中态由 JS 加 `on` 类驱动，不依赖 `:has()`。未激活的筛选胶囊也一并加深了边框与文字。
- **交互动效**：所有按钮 `:active` 缩小到 0.94、松开按 `btn-pop` 回弹（cubic-bezier 过冲）；选课成功后计数徽标弹跳一下（`badge-bump`），数字立即更新。
- **选课页筛选**：学年（2025-26 / 2026-27）｜学期（Term 1 / Term 2，互斥，2026-27 T2 置灰弹窗）｜分类（全部/通识/7 个学院）｜年级（Y1–Y4）｜课程搜索｜**只看本学期可选**｜**只看可选的**｜**自定义：仅校验时间**。特殊学生类型与特殊专业为两个**可折叠搜索项**（多选，仅作标签）。
- **三层折叠**（每层不同灰度）：学院（最深灰）→ 课程代码前缀如 `CSC`（中灰）→ 课程行（浅灰，只显示"代码 + 名称 + 分类标签"）。点击课程才展开属性与选课按钮；搜索或筛选生效时自动展开匹配层。
- **两种学院标签**（筛选栏下方有图例）：`开设 HSS`（实线、淡）= 该课由 HSS 开设，其他学院可选；`目标 HSS`（虚线、加粗、带学院配色）= 目标学生限 HSS，其他学院置灰（含由先修传递得到的限制）。展开课程后的属性区另有"开设学院"与"目标学生学院"两行，后者显示学院全名。
- **专业提示弹窗**：选中 `majorOnly` 课程时，弹窗列出该课的目标学生原文（如 `Y3-Y4 BME`），确认后仍可选；自定义模式下不弹。
- **学院-专业两级筛选**（筛选栏下方，**默认折叠**，上下两条）：① 按学院选课 —— 列出 7 个学院；选中后只显示该学院各专业的课程 + 通识课。② 按专业选课 —— 只列出官方专业表里该学院的专业（默认全部 31 个），选中后只显示该专业的课程 + 通识课。两级筛选生效时课程列表自动展开。通识课在两级的任何选择下都会一并显示（用户确认）。没有命中任何官方专业的课（490 门，含 PED 等）只在两级都不选时出现。
- **不可选标签**：`本学期未开课`（该学期没有排课）、`仅展示`（只有不可选节次）、`仅限 XX 学生` / `仅限 Y2–Y4` / `与已选 X 互斥` / `时间冲突：与 X Y`。
- **自定义模式**：勾选后顶部出现橙色提示条；取消勾选会提示有多少已选课程不再符合规则，并在左侧已选列表用红色"不符合规则"标出。
- **课表页**：选课后解锁；左侧已选课程栏（可换辅导课/移除），右侧周一–周五 08:30–21:50 网格自动填充；周末时段单独列在网格下方；顶部汇总"课程 N 门 · 时段 M 个 · **总学分 X** · 总课时 Y 小时 · 学期"。
- **折叠已选课程**：左侧栏顶部有 `«` 按钮，点一下把已选课程栏收成一条窄边（`«`↔`»` 互换、带提示文字），课表网格随之占满整行；再点一次展开。
- **导出课表图片**：课表右上角「导出图片 (PNG)」按钮——用 `<canvas>` 按当前学期重绘课表（标题、星期表头、时间刻度、午休纹、课程块、学院图例），块的位置与配色跟页面一致，`toBlob` 后下载为 `timetable_<学期>.png`。在拿不到 canvas 的环境里会提示"导出失败"而不会抛错。
- 切换学期或学年会清空已选课程。语言：右上角 中/EN 切换。调试入口：`window.__planner`。
